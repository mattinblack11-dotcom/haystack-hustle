# Haystack Hustle

First-person "needle in a haystack" simulator for the browser. Dig through hay, sell it, buy upgrades and find the hidden needle.

Play: open `index.html` in Chrome, or visit the GitHub Pages link for this repo.

Controls: WASD move, mouse look, click to use a tool, 1-6 tools, Q put away, Tab shop, U buy max, G gems, C style, V watch an ad for a boost, B all boosts, Esc pause.

Assets: KayKit (Kay Lousberg) and Kenney packs, CC0. FPS arms by para, CC0. See the license files in `assets/`.
